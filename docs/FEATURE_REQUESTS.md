# Feature Requests

Sammlung gewünschter Erweiterungen. Die Einträge sind noch nicht umgesetzt und keinem festen Release zugeordnet.

## 1. Farbwahl direkt im Originalbild

- [ ] Farben durch Anklicken einer Stelle im Originalbild auswählen können.
- Das gewünschte Verhalten im Zusammenspiel mit erkannten Farbgruppen und der Exportauswahl bei der Umsetzung festlegen.

## 2. Update-Funktion

- [ ] Eine Update-Funktion für HappyColorSplit einbauen.
- Bei der Planung festlegen, wie neue Versionen erkannt, angeboten und installiert werden sollen.

## 3. Schritt-für-Schritt-Anleitung

- [ ] Eine geführte Anleitung durch die Hauptfunktionen anbieten.
- Die jeweils erklärte Funktion mit einer gut sichtbaren Umrandung hervorheben und den zugehörigen Schritt kurz erklären.
- Die Steuerung rechts unten anzeigen: **Weiter**, **Zurück**, **Überspringen** und **Keine Tipps notwendig**.
- Bei der Planung festlegen, wann die Anleitung angeboten wird und wie sie später erneut aufgerufen werden kann beziehungsweise die Ablehnung von Tipps berücksichtigt wird.
